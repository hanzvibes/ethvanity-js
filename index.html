02 / What it does

Small by design.
Clear by default.

A focused command-line project, not a web wallet. Learn the workflow, inspect the implementation, and keep sensitive output under your control.

⌘
01 — LOCAL EXECUTION

Runs on your machine

Execute the CLI in your own Node.js environment. You control the runtime and where generated output is stored.

⌁
02 — PATTERN SEARCH

Prefix or suffix

Explore hexadecimal patterns at the start or end of an Ethereum address with the project's CLI options.

⌕
03 — OPEN SOURCE

Nothing hidden behind a form

Read the source, understand the trade-offs, and verify the behavior yourself before using it for anything important.

03 / Quick start

From repository
to terminal.

Start with the README for the exact current options. These commands show the basic repository workflow; use a trusted machine and review the source first.

STEP 01 / CLONE↘

Get the source

Clone the public repository and move into the project folder.

$ git clone https://github.com/hanzvibes/ethvanity-js
$ cd ethvanity-js
STEP 02 / INSTALL＋

Install dependencies

Use a current Node.js release and inspect the package scripts.

$ npm install
$ npm run
STEP 03 / RUN↗

Run the CLI

Check README usage and flags before starting a search.

$ npm run vanity
04 / Before you use it

Self-custody
means real care.

Vanity generation touches private-key material. Local execution is not the same thing as a security audit. Understand what the code prints and where that output goes.

Review the source ↗
!
Never share secret output

Private keys and recovery phrases are credentials. Never commit, upload, or paste them into chats.

!
Review the implementation

This project has not been independently security-audited. Read the source and verify the behavior before relying on it.

!
Test with disposable wallets

Do not use generated output to store funds until you have independently assessed the code and workflow.
