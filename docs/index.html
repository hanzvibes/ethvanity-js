What the project offers

A focused CLI.
Open source.

A straightforward CLI project for generating Ethereum addresses with a chosen hexadecimal pattern.

01 / LOCAL

Local execution

The CLI generates candidate keys in the Node.js process on your own machine. Protect that machine and its output files.

02 / FLEXIBLE

Prefix or suffix

Search for hexadecimal patterns at the beginning or end of an Ethereum address using the CLI options.

03 / OPEN SOURCE

Read before you run

Inspect the source and security caveats. This project has not been independently audited.

Get started

Run it locally.

You'll need Node.js installed. Check the repository README for current requirements and usage notes.

STEP 01

Clone the repo

git clone https://github.com/hanzvibes/ethvanity-js
cd ethvanity-js
STEP 02

Install dependencies

npm install
STEP 03

Start the CLI

npm run vanity

Security: generated output may contain private keys or recovery phrases. Never publish them, commit them to Git, or paste them into chats and online tools. The project is not security-audited; review the code and test with disposable wallets before considering any use involving funds.
